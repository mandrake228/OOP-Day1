# OOP-Day1

Учебный проект курса «База ООП», день 1: базовая модель банковских счетов.

## Что внутри

- `bank/errors.py` — ошибки модели: заморозка, закрытие, неверные данные, нехватка средств.
- `bank/enums.py` — статусы счёта и валюты.
- `bank/accounts.py` — абстрактный счёт `AbstractAccount` и обычный счёт `BankAccount`.
- `demo.py` — демонстрация, она же проверка модели.

## Запуск

```
python demo.py
```

Нужен Python 3.11 или новее. Устанавливать ничего не надо.

Демонстрация проходит по восьми разделам и сама себя проверяет. Если модель ведёт
себя как ожидалось, последняя строка сообщает об успехе, а код завершения равен 0.
